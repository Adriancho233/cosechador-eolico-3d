# Cosechador eólico 3D

Prototipo interactivo en 3D de un microaerogenerador hecho con materiales reciclados, pensado para el viento flojo de Turbo, Antioquia (1 a 3 m/s).

- Un solo archivo `index.html`: HTML, CSS y JavaScript, sin librerías ni instalaciones.
- Modelo 3D dibujado sobre `<canvas>` con un motor propio.
- Ocho piezas numeradas: rotor de PVC, eje y rodamientos, generador axial artesanal, rectificador activo, supercondensador, cargador con MPPT, batería de celdas 18650 y base.

Para verlo en tu computador, abre `index.html` con doble clic. La animación es ilustrativa y las proporciones son aproximadas.
